# 知本 · 金融与量化学习记录

从零开始学习金融基础与量化研究，保存学习网页、笔记和可复现的实验。

在线阅读：**[知本 · 金融学习手册](https://siyuqian.github.io/quant-learning/)**

GitHub Pages 从 `main` 分支根目录发布，后续推送会自动更新网页。

## 金融学习手册

现有手册包含 24 课，配有例子、自测题，以及复利、购买力、回撤和费用影响的交互实验。

- 第 1–3 课：投资、复利与通胀。
- 第 4–9 课：股票、债券、基金、ETF、订单、费用、杠杆与衍生品。
- 第 10–15 课：收益、现金流、风险、分散、资产配置与再平衡。
- 第 16–21 课：财务报表、企业研究、估值、经济、行为与投资计划。
- 第 22–24 课：数据检查、回测与第一个投资分析工具。

### 本地阅读

下载或克隆本仓库，用浏览器打开 `index.html`。四个网页文件需要保留在同一目录。

也可以在仓库目录启动静态服务器：

```sh
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。学习进度仅保存在当前浏览器的本地存储中，不会提交到仓库。

## 接下来的研究方向

1. 学习价格数据与收益率计算，画出累计收益曲线。
2. 用一只宽基股票 ETF 的历史日线数据，比较买入持有和规则固定的简单趋势策略。
3. 记录交易时点、数据口径、成本、最大回撤与失败条件。
4. 按时间保留未参与策略设计的数据，进行样本外检验。

第一阶段使用历史数据和模拟交易。每项实验记录问题、假设、数据来源、方法、结果和局限。
