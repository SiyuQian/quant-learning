# 合成数据实验

所有 CSV 均为手工构造，币种 CNY 仅作为统一记账单位。它们不是真实报价、指数或业绩记录，可随本仓库公开使用。`analysis.py` 使用 Python 3.10+ 标准库，无需安装依赖。

将程序和 CSV 下载到同一目录，在该目录运行：

```sh
python3 analysis.py --self-test
python3 analysis.py analyze net-values.csv
python3 analysis.py backtest prices.csv
python3 analysis.py backtest prices.csv --fee 0
python3 analysis.py backtest prices.csv --fee 2
python3 analysis.py actions corporate-actions.csv
python3 analysis.py analyze invalid-data.csv
```

最后一条应返回退出码 2，指出第 3 行重复日期。保留原文件，在副本中依次处理重复、缺失、非正、非法日期及混合币种，记录每项修改后重新运行；不要把日期排序或缺失补零当默认清洗。

| 文件 | 字段与单位 | 口径 |
| --- | --- | --- |
| `net-values.csv` | date（YYYY-MM-DD）、nav（正净值）、currency | 合成总回报净值，无外部现金流，已含分配，不再扣费用或另加股息 |
| `prices.csv` | date、open/close（元/单位）、currency | 独立合成标的，无股息拆股；用于给定成交价的回测 |
| `corporate-actions.csv` | date、raw_close（元/股）、split_ratio（新股/旧股）、dividend（当日每新股元）、currency | 独立原始价，一拆二后付股息，股息留现金，不再投资 |
| `invalid-data.csv` | date、nav、currency | 错误练习，不是可分析输入 |

程序严格检查列名、至少两行、规范日期、严格升序、重复、空值、非有限数、非正价格及混合币种。行动样本首行必须建立一股原始持仓，无当日拆股与分配；股息可为零，拆股倍数必须为正。CLI 对错误文件、无权限、非法输入给出错误并返回 2。

## 可手算参考结果

净值 100、120、90、110：累计收益 10%；1096 天按 365.25 天/年约定，CAGR `0.032272634735038386`，约 3.2273%。最大回撤 25%，高点 2023-01-01、低点 2024-01-01。截至 2025-01-01 未恢复；峰至终点、最长水下跨度均 731 天。水下跨度定义为前高点至恢复/观察终点的日历天数，含峰点至首个下跌观测的间隔，不是亏损观测数。

回测规则：初始现金 200；最近两日收盘均线，close 高于均线目标 1 单位，否则 0；收盘后可知，下一行交易日开盘执行；不重复相同目标，不借钱，现金不足记录拒单。每次实际买、卖均收固定费 1，现金收益 0，成交价为输入 open，未另计价差、滑点和税。期末不强制出售，持仓按最后 close 估值。

| 日期 | 昨日目标 | 开盘操作 | 费用 | 现金 | 持仓 | 收盘权益 | 明日目标 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2026-01-05 | 0 | 不交易 | 0 | 200 | 0 | 200 | 0 |
| 2026-01-06 | 0 | 不交易 | 0 | 200 | 0 | 200 | 1 |
| 2026-01-07 | 1 | 103 买 1 | 1 | 96 | 1 | 197 | 0 |
| 2026-01-08 | 0 | 100 卖 1 | 1 | 195 | 0 | 195 | 0 |

期末 195、收益 −2.5%、交易 2 笔、费用 2、最大回撤 2.5%、截至终点未恢复。市场暴露定义为收盘持仓观测数/总观测数，1/4=25%；没有用该比率声称与满仓风险相同。不计费期末 197（−1.5%）；每次费 2 时期末 193（−3.5%）。

基准也是一单位与剩余现金：首日开盘买入 100 并付买费 1，现金 99，末日股价 99，持仓估值净值 198（−1%）；若末日收盘清算再付卖费 1，则 197（−1.5%）。程序同时输出这两个口径；不要拿清算值和未清算值混比。三天跨度的形式年化会极端，JSON 中的 CAGR 仅为公式结果，不是业绩推断。

企业行动样本：第 1 日一股 100；第 2 日拆成两股，每股 50；第 3 日每股 49 并各分 1 元，持仓 98、现金 2。总财富每行都是 100。该样本不能再应用到已处理股息/拆股的净值上。

`--self-test` 验证回撤、恢复、恒定/下降序列、次开盘时点、现金与仓位、两边费用、基准、拒单、行动，以及空/单行/非法/重复/乱序/非有限/非正/缺失/混币输入。仓库另有 `python3 tests/check-examples.py` 的外部检查。

## 报告与限制

保存问题、数据和代码版本、Python 版本、运行命令/参数、观察日期、币种/现金流/费用口径、收益/回撤与恢复日期、交易数、暴露、基准、失败条件、尝试日志。可将 JSON 重定向到本地结果文件，不要提交账户信息。

程序只支持单资产教学；不处理外部现金流、真实交易日历/时区、公司行动回测、多资产、杠杆、真实撮合、税或生产交易。它拒绝乱序而不自动清洗。浮点数用于教学计算，显示可能有极小尾数；真实资金系统须采用其货币精度与结算规则。四天价格与四年净值用于核对计算，不支持收益优势、稳定统计量或未来预测。

数据定义与源阅读见课程 22–24。真实数据获取权不等于再分发权，使用前核对供应商定义与许可。
